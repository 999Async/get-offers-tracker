## 标签修订是否改变结论

为排除查询子集变化的干扰，固定历史四组排名和相同的 134 条入选查询，只替换相关性标签。以下是历史重放，不是本次新运行的时延或排序。

| 配置 | 原草稿标签 nDCG@10 | 最终 AI 标签 nDCG@10 |
| --- | ---: | ---: |
| BM25 | 0.9654 | 0.9441 |
| BGE-M3 | 0.9307 | 0.8949 |
| Hybrid / RRF | 0.9617 | 0.9439 |
| Hybrid + reranker | 0.9632 | 0.9520 |

重排相对词法从 −0.0022 变为 +0.0080，说明标签不完整足以改变对照方向。nDCG 的绝对值也因多相关岗位分级而变化，不能把它当作模型本身退步或进步。该检查不会消除 AI 判断误差或原语料偏差，仍不能据此选定生产模型。
