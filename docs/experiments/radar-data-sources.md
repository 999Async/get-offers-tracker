# 岗位雷达：用户数据源

2026-09-12，本机验收通过。

## 使用

岗位雷达 → 数据源，填写名称和腾讯文档公开链接。添加后立即读取，默认每日更新；可手动刷新、暂停或移除。移除数据源不会删除已经保存的投递记录。来源按登录账号隔离。

当前支持腾讯表格的表头映射（公司、岗位、招聘对象、地点、内推码、投递链接等），以及腾讯普通文档中“公司、内推码、链接”的表格结构。不是任意网站抓取器；私有文档、图片表格、其他文档平台尚不支持。

导入结果进入岗位目录，可以搜索和加入待投递。目前尚未同步到 Python 的语义检索索引，因此“简历匹配”与岗位助手搜索仍使用原有索引。

## 刷新行为

- 数据源保存于 D1；岗位快照压缩存储，成功时整体替换。公司、岗位内容、链接生成稳定 ID，重复项去重。
- 每次成功后安排 24 小时后的刷新。失败保留上次成功快照，一小时后重试，并在来源行显示失败原因。
- 刷新有租约，避免并发重复抓取；暂停和移除使正在运行的旧刷新失效。
- 本机 `npm run assistant:local` 同时启动调度进程，每分钟检查到期数据源。电脑休眠或服务停止期间不能刷新，恢复服务后补做。
- Cloudflare 构建包含 scheduled handler 和每五分钟检查的 Cron Trigger。需要迁移数据库并部署后才会在线生效；本次未部署生产环境。[Cloudflare Cron Triggers](https://developers.cloudflare.com/workers/configuration/cron-triggers/)
- 请求仅允许 HTTPS docs.qq.com，拒绝重定向；不向数据源传递用户账号凭据。单次读取限 90 秒、表格 5120 行、响应和解压文本 8 MB；每个用户最多 20 个来源。
