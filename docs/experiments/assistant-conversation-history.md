# 岗位助手历史对话

2026-09-12。

内容区移除重复“岗位助手”标题，材料、JD 与新对话按钮上移。顶部“岗位助手”下拉显示按更新时间排序的历史对话；选择记录会恢复消息、编辑后的草稿、固定材料版本、目标 JD 和未发送输入。刷新后打开助手会恢复最近更新的对话。移动端也保留顶部历史入口。

对话通过 `/api/assistant/conversations` 保存到产品数据库的 `assistant_conversations` 表。本地模式仍使用本机数据库，托管环境使用其 D1 绑定。所有读写绑定服务端登录账号；复合主键防止跨账号访问，修订号阻止旧窗口覆盖新记录。列表分页，不读取其他用户的数据。迁移为 `drizzle/0005_freezing_quentin_quire.sql`，已应用本机开发库，尚未部署或应用线上迁移。

输入、JD、材料选择和草稿编辑在空闲后自动保存；生成过程结束再保存完整消息。切换历史或新建前先等待保存成功，失败会保留当前内容并提示重试。请求发送失败会恢复输入，不把失败的用户消息重复附加到后续上下文。未保存时关闭或刷新页面使用浏览器离开提示。

原知识库引用段落不复制进历史数据库。历史中的回答和草稿是用户保存的既有产物，不代表重新验证过的事实；继续聊天时仍由 Agent 重新读取所选范围并校验引用。恢复的材料若已删除或换版，仍可阅读聊天，但必须新建对话并选择有效材料再生成。删除知识库材料不会删除用户已保存的聊天与草稿；原始引用摘录不在历史副本中。

此变更从启用后开始保存对话，无法补回此前仅在页面内存中、已经丢失的记录。这里保存的是产品会话，不是 Codex 内部推理或 Run Trace。
