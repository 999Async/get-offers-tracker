01

安装扩展

下载项目，选择正确文件夹

  1. 在 GitHub 项目页面点击 Code → Download ZIP，下载后双击解压。
  2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
  4. 选择解压后项目中的 browser-extension 文件夹。
不要选错：不能直接选择 ZIP，也不要选择整个 GetOffers 项目文件夹。
02

准备 profile.json

把简历交给可信 AI 整理

  1. 打开扩展，点击“下载空白模板”。
  2. 点击“复制 AI 生成提示词”。
  3. 向可信 AI 同时上传你的 PDF/Word 简历和 profile-template.json。
  4. 粘贴提示词，让 AI 返回可下载的 profile.json。
  5. 检查姓名、联系方式、日期和经历顺序，再导入扩展。
隐私提醒：简历可能包含电话、证件号和住址。只使用你信任的 AI；不愿上传时，可以手动填写空白模板。
03

导入资料

选择检查过的 profile.json

  1. 打开真正的招聘申请表单，并先完成登录。
  2. 点击浏览器工具栏中的 GetOffers 招聘表单助手。
  3. 在“选择生成并检查过的 profile.json”下选择文件。
  4. 看到“已导入”后，点击“扫描并预览”。
导入失败？扩展会拦截空白模板和错误格式。重新让 AI 按原模板生成即可。
04

扫描与填写

先看颜色，只填写绿色字段

绿色 · 可填
高置信度普通字段，可以自动填写。
黄色 · 人工
下拉框、日期、附件或有歧义的字段。
灰色 · 缺值
资料中没有内容，或扩展暂时无法识别。
  1. 先点击“扫描并预览”，检查匹配结果。
  2. 确认后点击“填写绿色字段”。
  3. 逐项检查页面，手动完成黄色和缺值项。
  4. 由你本人确认协议、验证码、附件和最终提交。

常见问题

卡住时先检查这四项

按钮为什么是灰色的？

先导入填写好的 profile.json。“填写绿色字段”要在完成一次扫描后才会启用。

下拉框和日期为什么没有自动填写？

很多招聘网站使用自定义组件，看似写入并不代表真正选中，因此扩展把它们保留为黄色人工项。

多段经历为什么顺序不对？

先在网页上手动创建足够数量的经历卡片，再确认 profile.json 中的数组顺序与简历一致。

更新代码后还是旧效果？

进入扩展程序页面点击“重新加载”，然后刷新已经打开的招聘页面。
